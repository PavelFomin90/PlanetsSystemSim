# Отчет о покрытии кода

Этот отчет автоматически генерируется при запуске тестов с флагом --coverage.

## Как запустить

```bash
npm run test -- --coverage
```

Или для наблюдения за изменениями:

```bash
npm run test:watch -- --coverage
```

## Конфигурация

Покрытие кода настраивается в `jest.config.js`:

- `collectCoverage: true` - включает сбор покрытия
- `coverageDirectory: 'coverage'` - директория для отчетов
- `coverageReporters` - форматы отчетов
- `coveragePathIgnorePatterns` - файлы, исключенные из анализа

## Рекомендации

- Стремитесь к покрытию не менее 80% для ключевых модулей
- Фокусируйтесь на покрытии бизнес-логики
- Регулярно проверяйте отчеты в директории `coverage/`
- Обновляйте тесты при изменении кода
