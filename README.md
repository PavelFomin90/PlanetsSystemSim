 # Планетные Системы Симулятор

## Установка и Запуск

1. **Клонирование репозитория**: Склонируйте репозиторий на ваш локальный компьютер, используя команду:
    ```sh
    git clone https://github.com/your-repo/planetssim.git
    cd planetssim
    ```

2. **Установка зависимостей**: Установите все необходимые зависимости, выполнив команду:
    ```sh
    npm install
    ```

3. **Запуск приложения**: Запустите приложение в режиме разработки с помощью команды:
    ```sh
    npm start
    ```
    Это запустит webpack-dev-server, и вы сможете просматривать ваше веб-приложение по адресу `http://localhost:8080`.

4. **Сборка приложения**: Для создания оптимизированной версии приложения используйте команду:
    ```sh
    npm run build
    ```
    Это создаст файлы в папке `dist`, которые можно развернуть на сервере.

## Скрипты

- **npm start**: Запускает webpack-dev-server в режиме разработки без минификации и оптимизации кода.
