# Feature: Панель спис��а планет

## Описание

Добавить панель, отображающую список всех планет, добавленных в симуляцию. Панель позволяет пользователю просматривать все существующие тела в системе и получать дополнительную информацию о каждом из них по клику.

## Цели

- Предоставить пользователю обзор всех планет в симуляции
- Обеспечить легкий доступ к детальной информации о каждом теле
- Улучшить навигацию по системе, особенно при большом количестве планет
- Сделать симуляцию более образовательной и информативной

## Требования

### Функциональные

1. **Отображение панели**
   - Панель отображается в левом верхнем углу экрана
   - Имеет кнопку для сворачивания/разворачивания панели
   - По умолчанию развернута при запуске

2. **Список планет**
   - Отображает все планеты, добавленные в систему через `System.addPlanet()`
   - Каждый элемент списка содержит:
     - Имя планеты
     - Цветовой индикатор (квадратик/круг того же цвета, что и планета)
     - Массу (в условных единицах)
   - Элементы списка упорядочены по имени планеты

3. **Интерактивность**
   - По клику на элемент списка:
     - Открывается модальное окно с детальной информацией
     - Камера плавно перемещается к выбранной планете (фокусировка)
   - При повторном клике на ту же планету - информация скрывается

4. **Детальная информация (во всплывающем окне)**
   - **Имя объекта** - понятное название
   - **Масса** - в условных единицах, округлённая до 2 знаков
   - **Радиус** - визуальный размер тела на экране (в пикселях)
   - **Цвет** - визуальное отображение цвета
   - **Скорость** - текущая длина вектора скорости (модуль)
   - **Ускорение** - текущее ускорение
   - **Координаты** - текущие координаты в системе (X, Y)
   - **Расстояние до центра системы** - расстояние от планеты до центра координат
   - **Родительское тело** - тело, вокруг которого вращается планета (если есть)

5. **Автообновление**
   - Список автоматически обновляется при добавлении или удалении планет из системы
   - При изменении свойств планеты (имя, масса, цвет) элемент списка также обновляется

6. **Поиск и фильтрация**
   - Поле поиска в верхней части панели для фильтрации планет по имени
   - Возможность сортировки по массе, имени или расстоянию до центра

### Нефункциональные

- Производительность: отображение панели не должно влиять на FPS симуляции
- Адаптивность: панель корректно отображается на экранах разного размера
- Доступность: поддержка клавиатурной навигации по списку
- Совместимость: корректная работа с существующими компонентами (InfoPanel, TranslateController)

## Техническая реализация

### Компонентная архитектура

Панель будет реализована как отдельный компонент с использованием существующей архитектуры компонентов. Будут созданы следующие элементы:

1. **PlanetsListPanel** - основной компонент панели, отображающий список планет
2. **PlanetInfoModal** - модальное окно для отображения детальной информации о планете

Компонент будет интегрирован в существующую систему через механизм рендеринга, аналогичный уже реализованной InfoPanel.

### Интеграция с системой

1. Панель будет получать ссылку на экземпляр System для доступа к списку планет
2. Будет реализован механизм периодической проверки изменений в системе планет
3. При инициализации симуляции панель будет автоматически подключаться к системе

### Визуальный дизайн

Панель будет соответствовать существующему стилю интерфейса симуляции:
- Темный полупрозрачный фон (rgba(0, 0, 0, 0.7))
- Белый/светлый текст для контраста
- Закругленные углы
- Небольшие тени для объема
- Адаптивные размеры

Модальное окно будет затемнять фон и отображаться поверх всех элементов, обеспечивая фокусировку на информации о планете.

## Дальнейшие улучшения (опционально)

- Добавить иконку планеты в список (маленький круг того же цвета)
- Реализовать сортировку по различным параметрам (масса, расстояние до центра)
- Добавить фильтрацию по массе (малые, средние, крупные планеты)
- Включить возможность смены режима отслеживания прямо из списка
- Добавить кнопку для центрирования системы (сброса камеры)
- Реализовать перетаскивание элементов списка для изменения порядка отображения
- Добавить экспорт списка планет в CSV/JSON формат

## Завершение

После реализации:
- Проверить отображение панели с разным количеством планет
- Убедиться, что панель не влияет на производительность симуляции
- Протестировать поведение при изменении размера окна
- Проверить корректность работы поиска и сортировки
- Убедиться в правильной работе автообновления списка при добавлении/удалении планет
