# Планетные Орбиты Симулятор

Это веб-приложение позволяет вам исследовать систему планетных орбит, создав и наблюдая за движением различных небесных тел в космосе. Вы можете:

1. **Масштабировать изображение** с помощью колесика мыши или нажимая клавиши `Q` для увеличения и `A` для уменьшения.
2. **Перемещать холст** по экрану с помощью клавиш со стрелками.
3. **Наблюдать за планетами** в их движении вокруг центрального тела (например, Солнца). Орбиты планет отображаются в виде замкнутых ломаных линий, соединяющих предыдущие координаты планет.
4. **Взаимодействовать с холстом**, кликая по нему для получения координат и фокусируясь на конкретной планете при нажатии кнопки мыши.
5. **Наблюдать за изменениями** в движении планет, когда вы манипулируете холстом с помощью клавиатуры или перемещаете курсор мыши.

Взаимодействие с приложением происходит через графический интерфейс, где вы можете исследовать динамику системы планетных орбит в интерактивном режиме.
